# 全国肝病联盟与2030慢性肝病行动专题知识库

面向**全国肝病专病联盟建设**与 **2030 年消除病毒性肝炎公共卫生危害目标**的专题型医学知识库。

围绕『**筛-诊-治-管-康**』全流程策略，系统收录、溯源、评级慢乙肝领域高质量循证证据，支撑联盟规范化诊疗、临床治愈专病管理、HCC 全程管理与策略研究。

---

## 项目定位

- **目标**：2030 年消除病毒性肝炎公共卫生危害（新发感染降 90%、死亡降 65%、诊断率 90%、治疗率 80%）
- **时间范围**：2021 年及以后优先；2019-2020 年仅纳入奠基性文献
- **第一阶段规模**：500 篇（2026-08-28 扩库；中国证据 ≥60%，A+B 级 ≥70%，P0+P1 优先 ≥50%）

## 数据规范

### 55 字段卡片体系（10 组）

A 标识与溯源 · B 题录信息 · C 中国属性 · D 方法与证据 · E 人群特征 · F 治疗方案 · G 基线指标 · H 疗效与结局 · I 价值与定位 · J 质量与分级

### 双维评级

- **证据等级**：A（指南/共识/政策/系统评价）→ B（RCT、大规模前瞻性真实世界研究）→ C（回顾性队列/病例对照）→ D（会议摘要/专家意见）
- **关注优先级**：P0（策略/联盟建设决定性证据）→ P1（临床路径优化重要证据）→ P2/P3（参考）

### 去重五规则

1. 唯一键：PMID → DOI → URL 逐级去重
2. 一稿多形态（会议摘要+预印本+正式论文）只留主卡
3. 指南新旧版本保留历史版本
4. 中文解读（公众号等）不单独建卡，仅入「二次解读链接」
5. 标题相似度复核

## 数据来源与合规声明

- **线索源**：ima 知识库「肝斗士-肝脏修复」（雨露肝霖公众号转存 PDF）——仅作线索来源
- **证据源**：全部条目均溯源至 PubMed / 期刊官网 / 官方文件的 **PMID / DOI / 官方链接**
- **未报告原则**：文献未报告的数据一律填「未报告」，不编造、不猜测
- **隐私合规**：本库仅收录**公开文献题录与摘要数据**，不含任何患者个人信息，可安全公开

## 使用方式

1. **在线问答**：👉 **[证据问答应用（GitHub Pages）](https://fdd77931-arch.github.io/hbv-hcc-plan/)** — 手机/电脑浏览器直接访问，基于主表证据问答，带证据等级与策略建议
2. **主表查询**：`01_主表/` 中 CSV/XLSX 可用 Excel/WPS/Python 直接检索筛选
3. **专题阅读**：`03_专题页/` 提供专题级综述
4. **问答应用构建**：主表更新后运行 `04_问答应用/build_app.py` 重新生成根目录 `index.html`
